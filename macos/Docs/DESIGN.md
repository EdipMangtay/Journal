# Design system
Inspiration studied: [Linear](https://linear.app), [Raycast](https://www.raycast.com), [Arc](https://arc.net). Their compact hierarchy and keyboard-led interaction inform the design; no layouts or assets are copied.

- Canvas #0C0F13, panel #14191F, raised #1B222A; light theme uses adaptive equivalents.
- Ink #EEF2F5, secondary #A0AAB7. Mint #66D8AD represents positive outcome; coral #F17F85 represents negative outcome. Amber #E9B66D represents process warnings, including profitable invalid trades.
- Spacing 4/8/12/16/24/32. Radius 12 for cards, 8 for controls. 1px low contrast borders.
- SF Pro for prose, SF Mono for labels/numbers; tabular digits keep metrics stable.
- 160–250ms motion; reduced-motion and preference disable nonessential transitions.
- Score hierarchy: process band appears before equity. All signals have text as well as color.
- Sidebar collapses to symbol rail. Dense data tables use native scrolling and sorting.
